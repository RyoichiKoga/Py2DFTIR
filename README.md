# Py2DFTIR
This code converted the interferogram data cube measured by 2D FT-IR into the spectrum data cube.
The code was used in the mid-IR measurement of the C2H4 frost (Koga et al., 2024, EPS, https://doi.org/10.1186/s40623-024-01976-y ) and N2O frost (Takama et al., under review), which simulated the environment of the solar system bodies.
Place fft_2DFTIRdata_ver1.py and Py2DFTIR folder in the same directory and run fft_2DFTIRdata_ver1.py using Python.

command line input
fft_2DFTIRdata_ver1.py (interferogram file directory) (dir + Output (specta) file name)
